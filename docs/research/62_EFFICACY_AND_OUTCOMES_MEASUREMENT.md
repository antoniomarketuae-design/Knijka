# Efficacy and Learning Outcomes Measurement

> Status: skeleton — 2026-07-07. This document operationalizes the North Star: without measurement, "safer drivers" is a slogan. Efficacy data is also the future B2B/government sales weapon.

## Scope of this document (to be developed)

- **Outcome hierarchy:** (1) in-product learning gains (mastery, retention curves, hazard-perception scores) → (2) real theory-exam pass rates of our users vs national average **[baseline data needed from ИААА statistics]** → (3) practical-exam pass rates via partner schools → (4) long-term: insurance/incident data partnerships.
- **Measurement design:** cohort definitions, self-selection bias controls (our users may simply be more motivated), what we can honestly claim at each evidence level.
- **In-product instrumentation:** which events prove learning (mistake recurrence decline, transfer between theory and sim contexts, spaced-retention performance).
- **Readiness prediction validation:** the "93% pass probability" feature is a model — it must be calibrated against real exam outcomes users report back, or it's fiction.
- **Research partnerships:** Bulgarian universities / road-safety NGOs for credible independent evaluation (also a PR and government-relations asset).
